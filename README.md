#  OPS HUB(사내 통합 운영 관리 콘솔)
회사에서 운영하는 웹사이트와 데이터베이스 (DB) 를 연결해, 사용자 문의 내역과 시스템 장애 발생 로그를 실시간으로 확인하고 관리할 수 있도록 만든 내부 관리자 도구입니다. 이를 통해 운영 팀은 빠르게 문제를 파악하고 조치할 수 있으며, 시스템의 안정적인 운영과 효율적인 유지보수를 지원합니다.


# 개발 배경 및 기획 의도

실무 수준의 백오피스(Back-office) 운영 시스템을 직접 구축하고자 기획한 프로젝트입니다. 
단순히 화면과 기능을 구현하는 데 그치지 않고, 현업 백오피스 운영 실무를 더 깊이 있게 이해하기 위해 '현직자 멘토링'을 거치며 아키텍처와 기능을 발전시켰습니다. 이 과정에서 다음과 같은 치열한 고민들을 거쳤습니다.

- "어떻게 하면 관리자가 방대한 데이터를 안전하고 빠르게 다룰 수 있을까?"
- "실제 서비스 운영 중 장애가 발생했을 때, 백엔드와 프론트엔드는 이를 어떻게 감지하고 대응해야 할까?"
- "동시 수정 요청이 들어왔을 때 데이터 정합성을 어떻게 보장할 수 있을까?"

# 주요 커밋 히스토리

- `feat`: 로그인 및 세션 기반 인증 처리 구현
- `feat`: 관리자 회원 목록 조회 및 권한 필터 구현
- `feat`: 문의 도메인 CRUD 및 관리자 권한 검증 로직 추가
- `refactor`: 유지보수성 향상을 위한 도메인 패키지 계층 구조 정리
- `test`: 회원 및 문의 서비스 핵심 비즈니스 로직 단위 테스트 추가
- `perf`: 조회 인덱스 및 캐싱 전략 적용을 통한 성능 개선
- `feat`: 낙관적 락을 이용한 동시 수정 방지 구현
- `feat`: APM 장애 감지 및 Webhook/Slack 알림 연동
- `fix`: Vercel 프론트엔드 배포 주소 CORS 허용 설정
- `chore`: 환경변수 템플릿(`.env.example`) 및 민감 정보 관리 체계 정비
